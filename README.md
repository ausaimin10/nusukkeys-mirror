# NusukKeys — Backup Mirror (static only)

A self-contained backup of the NusukKeys site that works with **no server
and no database at all**. If the main site (Cloudflare Pages + D1) is ever
unreachable, this mirror still lets people get codes.

## What is in this folder

- `index.html` — the whole mirror (inline CSS + JS, one file).
- `codes.json` — the public code list (13,721 codes, same file the main
  site serves at /codes.json). Regenerate it from the seed with
  `node ../rebuild/make-codes-json.mjs` and copy it here whenever the
  seed grows.
- `codes-head.json` — the first 400 codes (17 KB), generated by the
  same script; the page loads this first and becomes usable at once,
  then loads the full list in the background. Copy it with codes.json.
- `sw.js` — service worker: after the first visit the mirror opens
  from cache even when its host is down, and redirects to a live host.
- `_headers` — Cloudflare Pages headers: long cache + CORS for the two
  code files, so other hosts can fetch this mirror's list as a fallback.
- `DEPLOY-OTHER-HOSTS.md` — how to publish this folder on Netlify /
  Vercel / GitHub Pages / Surge / Firebase / Render.

## How it works

- The page loads `codes-head.json` (first 400 codes, 17 KB) and filters
  it in the browser: dispenser, grid, search, filters (Remaining / Newly
  Added / Used / All), copy, skip, undo, and the "Open in Nusuk app"
  deep link — then loads the full `codes.json` in the background so the
  browser can search all 13,721 codes. If this host's files fail, it
  tries the same files on the main site and the second backup (each
  with its own timeout), and if no code list loads at all it counts
  down 5 seconds and moves the visitor to the next live host (each
  candidate is probed first; a `?fo=` marker stops it ever looping).
- Used codes are remembered only in that browser (localStorage
  `mk_mirror_used_v1`). There is no account, no cross-device sync, and
  no share form — sharing needs the main site's database. The page says
  so and links back to the main site.
- The first code every new visitor sees is NG-0GjkSPjM (the mandatory
  first code, already in the code list — never duplicated). The page
  also has the same 5-platform share bar (Facebook, WhatsApp, Telegram,
  X, LinkedIn) with "Please share this for the benefit of the Ummah.",
  the "Created by Hasan Mahmud" credit, and the footer notice that the
  page stays active until December 20, 2026 (unless Nusuk changes the
  date of its Umrah campaign).

## How to deploy (one of these, free)

- **Cloudflare Pages (already done for this mirror):** the mirror is
  also deployed as its own Cloudflare Pages project
  (`nusukkeys-mirror`), same account as the main site — no second
  account, no second database.
- **Netlify Drop:** drag this whole folder onto https://app.netlify.com/drop
  (free account). You get a `*.netlify.app` URL.
- **GitHub Pages:** put this folder in a repo, enable Pages for it.
- **Vercel:** drag the folder into a new project (or `vercel --prod`).
- Any static host works — there is no build step and no server code.

Keep the mirror's `codes.json` fresh: whenever the main site's seed
grows, regenerate it and re-upload the folder.
