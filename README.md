# NusukKeys — one site, every host

This folder holds the **exact same website** as the main site
(https://nusukkeys-cu9.pages.dev/) — the same files, the same design,
the same code. There is no separate "mirror version" any more. Every
host serves identical files, so a visitor cannot tell which host is
serving them, and a move to another host changes nothing they see.

## What is in this folder

- `index.html`, `app.js`, `styles.css`, `favicon.svg`,
  `manifest.webmanifest`, `og-image.png` — the full site.
- `codes.json` — the public code list (13,721 codes, same file the main
  site serves). Regenerate it from the seed with
  `node ../rebuild/make-codes-json.mjs` and copy it here whenever the
  seed grows.
- `codes-head.json` — the first 400 codes (17 KB), generated by the
  same script; the page loads this first and becomes usable at once,
  then loads the full list in the background. Copy it with codes.json.
- `sw.js` — service worker: after the first visit the site opens from
  cache even when its host is down, and redirects to a live host.
- `_headers` — Cloudflare Pages headers: long cache + CORS for the two
  code files, so other hosts can fetch this host's code list as a
  fallback.
- `DEPLOY-OTHER-HOSTS.md` — how to publish this folder on Netlify /
  Vercel / GitHub Pages / Surge / Firebase / Render.

## How it works

- The page loads `codes-head.json` first, then the full `codes.json`,
  and filters them in the browser: dispenser, grid, search, filters
  (Remaining / Newly Added / Used / All), copy, skip, undo, the "Open
  in Nusuk app" deep link, the share bar, and the Sponsor Hosting card.
  If this host's files fail, it tries the same files on the other hosts
  (each with its own timeout), and if no code list loads at all it
  counts down 5 seconds and moves the visitor to the next live host
  (each candidate is probed first; a `?fo=` marker stops it ever
  looping).
- On the main site the database records each visitor's used codes. On
  a host with no database the same page serves codes locally as a guest
  instead, and used codes are remembered only in that browser
  (localStorage `mk_local_used_v1`), so the one-time rule still holds
  across reloads and host switches. Adding a code to the shared pool
  needs the main site's database — on a static host the share form
  shows an error instead of silently failing.
- The first code every new visitor sees is NG-0GjkSPjM (the mandatory
  first code, already in the code list — never duplicated). The page
  also has the same 5-platform share bar (Facebook, WhatsApp, Telegram,
  X, LinkedIn) with "Please share this for the benefit of the Ummah.",
  the "Created by Hasan Mahmud" credit, and the footer notice that the
  page stays active until December 20, 2026 (unless Nusuk changes the
  date of its Umrah campaign).

## How to deploy (one of these, free)

- **Cloudflare Pages (already done):** this same folder is deployed as
  its own Cloudflare Pages projects (`nusukkeys-mirror`,
  `nusukkeys-backup`), same account as the main site — no second
  account, no second database.
- **Netlify Drop:** drag this whole folder onto https://app.netlify.com/drop
  (free account). You get a `*.netlify.app` URL.
- **GitHub Pages:** put this folder in a repo, enable Pages for it.
- **Vercel:** drag the folder into a new project (or `vercel --prod`).
- Any static host works — there is no build step and no server code.

Keep the `codes.json` fresh: whenever the main site's seed grows,
regenerate it and re-upload the folder.
